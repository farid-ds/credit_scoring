# Credit Scoring 

Проект построения модели кредитного скоринга на данных Give Me Some Credit. 

## Цель 

Предсказать вероятность возникновения финансовых трудностей у клиента на горизонте двух лет и исследовать, как результаты модели могут использоваться для принятия кредитных решений. 

## Данные

Данные не хранятся в репозитории.

Источник: Kaggle — Give Me Some Credit.

Для воспроизведения проекта необходимо скачать датасет и поместить файлы в `data/raw/`.
